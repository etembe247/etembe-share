Send files and text directly between compatible browsers using an encrypted WebRTC data channel. This version uses manual offer/answer exchange: no account or file-storage server is needed, but you must exchange pairing text between devices.

Important deployment notes

HTTPS required

Host over HTTPS (or localhost) for reliable browser support. STUN helps discover routes, but restrictive networks may require a TURN relay. This version does not include a TURN service.

Manual pairing by design

Offers/answers contain network connection information. Exchange them privately. QR pairing, automatic discovery, Bluetooth, username-based relay, and guaranteed internet-free transfer are not implemented.

Test before relying on it

WebRTC data channels encrypt data in transit, but peer identity is not independently verified by this static app. Only connect with a trusted recipient and test your exact browsers/networks before operational use.
